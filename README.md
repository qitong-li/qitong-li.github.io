# qitong-li.github.io

Personal academic website for Qitong Li, built with Jekyll and hosted on GitHub Pages.

**Live site:** https://qitong-li.github.io

## Stack

- Jekyll 4.4 with a custom minimal single-column layout
- Deployed via GitHub Actions → GitHub Pages

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

Site will be available at `http://localhost:4000`.
